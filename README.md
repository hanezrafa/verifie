# Verifie

Chrome extension for viewing and analyzing Google Docs edit history with real-time tracking.

## Features

- **Document** - View document info and edit history
- **Replay** - Playback edit history with timeline, play/pause, speed control
- **Stats** - Word count, deletes, time spent, edits + export JSON
- **Breakdown** - Pie chart breakdown (IPs, cameras, referrers, events)
- **AI Detect** - AI vs human content detection with percentage
- **Tracking** - Real-time character count and editing duration tracking

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable **Developer mode** (top right toggle)
3. Click **Load unpacked** and select this folder
4. Open a Google Doc to use the extension

## Tech Stack

- Chrome Extension Manifest V3
- Pure HTML/CSS/JavaScript (no frameworks)
- Canvas API for charts
